# OCR support — deferred, no runtime implementation
Entry points: PdfService.extractText and RagMaterialService.processAndIndexPdf. After native text extraction, assess each page for missing/low-quality text; render only affected pages and pass them to a local Tesseract adapter with language selection. Keep native text on readable pages, OCR only missing pages, preserve page numbers and extraction provenance. Never concatenate duplicate native/OCR text.
Retain the original PDF before indexing; expose OCR-required/queued/running/failed/ready states via RagJobsService. Process within the existing 10 MB/50-page limits with bounded concurrency, per-page timeout, cancellation, and temporary-file cleanup. Display low-confidence pages for review; never report blank output as indexed. Existing chunking/embedding follows successful extraction. No document content may control execution.
Validation: scanned-only, mixed native/scanned, rotated, blank, unreadable and multilingual pages; cancellation, limits, original preview after extraction failure, no duplicate text, citation page accuracy. No OCR dependencies, endpoints, workers, or execution are added by this delivery.
