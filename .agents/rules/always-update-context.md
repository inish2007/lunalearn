# Rule: Always Update context.md

Whenever making changes to the codebase, resolving bugs, integrating features, or completing a user request:
1. Always update `context.md` to reflect the latest status, feature wire-ups, architecture notes, and system health.
2. Ensure `context.md` remains the definitive, living source of truth for the project state.
3. Keep track of any verified endpoints, changes in dependencies, themes, or data models.
